## Cómo se usa

1. **`00-general`** — se hace una vez por máquina, no por proyecto.
2. **`01-stacks`** — entra por el tipo de proyecto. Ahí está la checklist.
3. **`02-tools`** — cada paso de la checklist enlaza aquí, a la herramienta.
